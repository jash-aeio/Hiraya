# The pitch kit (M-02)

Gate A input. Three pieces, all drafts as of 2026-09-26, all written to be read aloud or handed over rather
than filed.

| File | What it is | Where it is used |
|---|---|---|
| [`ONE_PAGE_SUMMARY.md`](ONE_PAGE_SUMMARY.md) | One page for the school head. Problem, the loop, what the school gets, what it costs, how learner data is handled, and the honest parts | **Leave it behind.** `SETUP_GUIDE.md` §8 |
| [`SLIDE_DECK.md`](SLIDE_DECK.md) | Five slides — problem → demo → privacy and consent → what we need → timeline. Each carries what goes *on* the slide and what to *say* | Runs 8–10 minutes, leaving the hour for the phone |
| [`PHONE_DEMO_SCRIPT.md`](PHONE_DEMO_SCRIPT.md) | The exact three-minute click path on the deployed demo, with the two personas to pick and what to do when it breaks | **Rehearse it.** It is the only part of the hour anyone remembers |

**Markdown is the source, not the deliverable.** These are written so a PDF and a deck can be produced from
them without the content living in two places — the same reason `ASSET_CHECKLIST.md` keeps the app icons as
a drawing rather than a committed PNG. Rendered PDFs and decks, if produced, do not belong in the
repository.

## Two things a future session should know

**`ASSET_CHECKLIST.md` §1.9 lists a fourth piece** — a **privacy one-pager for the DPO**, anticipating their
questions before the first meeting. `WORKSTREAMS.md` M-02 and `SETUP_GUIDE.md` §8 both name only three, and
§8 says to bring *"the one-page PDF, and the 5-slide deck. Nothing else."* The three here are the three M-02
scoped. The fourth is unwritten and unbooked; it is Gate **B** material by content, so the disagreement is
about which gate it belongs to rather than about whether to write it.

**`SETUP_GUIDE.md` §8 step 2 asks for a demo of the adviser approval flow, which Phase 0 did not build.**
Event approval is Phase 2. `PHONE_DEMO_SCRIPT.md` handles this by naming the gap out loud and turning it
into the question worth asking the adviser instead — but the guide's instruction is currently unfollowable
as written, and should be either reworded or accepted as a known gap at Gate A.
